评测Evaluation

Relay-Bench: Evaluating LLMs on Multi-Domain Reasoning ChainsRelay-Bench: Evaluating LLMs on Multi-Domain Reasoning Chains

问题：单域基准已经饱和，但真实任务往往把视觉、代码、数学、检索、数据分析串在一条链上；现有基准很少测“跨域接力”。
证据位置：摘要给出 21 页、7 图的纯文本基准，题目由 2–13 个子问题拼成，允许模型用代码执行、联网与工具；公开结果里得分最高的模型 GPT-5.5（xHigh）只有 43.3%。
作者自陈局限：只测文本输入输出；题目的“上下文膨胀”和编码层是人为加的复杂度，和真实工作流的噪声不完全同构；模型可用工具，分数受 harness 影响大；没有开源榜单的长期污染检查。
它没主张的：不是通用能力排行榜；不是多模态基准；不是“低于 43% 就不会做跨域任务”的结论。Problem: single-domain benchmarks are saturated, while real tasks string vision, code, maths, retrieval and data analysis into one chain; few benchmarks measure that cross-domain relay.
Where the evidence sits: the abstract describes a 21-page, 7-figure text-only benchmark whose items chain 2–13 subproblems and explicitly allow code execution, web search and tools; the leading model, GPT-5.5 (xHigh), scores 43.3%.
What the authors say about limits: text-only input and output; the deliberate context bloat and prompt encoding add artificial complexity that is not identical to real workflow noise; tool access makes scores harness-dependent; there is no long-term contamination check for a public leaderboard.
What it does not claim: a general capability ranking; a multimodal benchmark; that a model below 43% cannot do cross-domain work.

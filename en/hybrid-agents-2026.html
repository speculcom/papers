Reasoning

Hybrid Reasoning Agents

Problem: text reasoning is inspectable and can call tools but costs tokens; latent reasoning saves tokens but lacks native tool access and readability; can a single generation process switch between the two.
Where the evidence sits: HybridAgents uses a lightweight HybridLink to switch between text and latent modes and keeps a continuous working memory across turns for lossless hybrid context; HybridSFT and HybridRL post-training coordinate the modes; across three model scales and 11 benchmarks in mathematics, science, medicine, search and agentic reasoning it improves performance by 10.4%, cuts tokens by 35.5–54.7%, speeds inference by 1.8–2.6× and saves 2.7–3.7× cost.
What the authors say about limits: three model scales and 11 benchmarks; latent-mode interpretability remains limited; tool use and multi-turn working memory require architectural changes; production deployment and safety evaluation are not covered.
What it does not claim: not that every reasoning task should move to latent space; not that 10.4% is a uniform gain across all tasks; not that token savings preserve the same interpretability.
